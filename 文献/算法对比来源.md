# 算法对比的原始来源

检索日期：2026-10-31。这是围绕指定四种算法的定向核对，不是系统综述。按作者论文、原始会议论文和固定版本官方文档核对题名、年代、核心数据结构及实现边界。

| 算法或方法 | 原始文献 | 核对位置与用途 |
|---|---|---|
| GSP | Srikant R, Agrawal R. Mining Sequential Patterns: Generalizations and Performance Improvements. EDBT 1996: 3–17. DOI: 10.1007/BFb0014140. [原文](https://rsrikant.com/papers/edbt96.pdf) | 原文算法部分的逐层候选生成与支持度剪枝。GSP 对应 1996 年论文，不把 1995 年最初的序列挖掘论文当作 GSP 原文。 |
| PrefixSpan | Pei J, et al. PrefixSpan: Mining Sequential Patterns Efficiently by Prefix-Projected Pattern Growth. ICDE 2001: 215–224. DOI: 10.1109/ICDE.2001.914830. [原文](https://www.cs.sfu.ca/~jpei/publications/span.pdf) | 前缀投影、递归模式增长。已有本地原文 `文献2.pdf`。 |
| SPADE | Zaki M J. SPADE: An Efficient Algorithm for Mining Frequent Sequences. Machine Learning 42 (2001): 31–60. DOI: 10.1023/A:1007652502315. [原文镜像](https://philippe-fournier-viger.com/spmf/SPADE.pdf) | 第 4–5 节的垂直 ID 列表、时序连接和等价类。已有本地原文 `文献3.pdf`。 |
| SPAM | Ayres J, et al. Sequential PAttern Mining using A Bitmap Representation. KDD 2002: 429–435. DOI: 10.1145/775047.775109. [作者原文](https://www.cs.cornell.edu/johannes/papers/2002/kdd2002-spam.pdf) | 第 1.1 节的主存假设；第 2 节的位图、深度优先搜索及 S-step / I-step。本文只实现单项目步骤下的 S-step；Python 每顾客整数位图不等同于论文的原始 C++ 存储实现。 |
| 分区候选原则 | Savasere A, Omiecinski E, Navathe S. An Efficient Algorithm for Mining Association Rules in Large Databases. VLDB 1995: 432–444. [原文](https://www.vldb.org/conf/1995/P432.PDF) | 第 3 节的分区两遍扫描和局部候选并集思想。原文对象是频繁项集；本项目对“顾客序列支持数可加”的条件单独证明完备性。 |
| Spark PrefixSpan | [Spark 4.0.1 官方文档](https://spark.apache.org/docs/4.0.1/ml-frequent-pattern-mining.html) | `minSupport`、`maxPatternLength`、`maxLocalProjDBSize` 参数和允许多项目步骤的输出结构。原生版本仍搜索其模式空间，最终筛选单项目步骤。 |

实现说明：四个 Python 内核统一输入、编码、模式语言、阈值、分区和全局计数，仅比较上述核心搜索策略。没有复刻原作者全部工程优化、时间约束、分类层级或篮内扩展，也没有将原论文中的加速倍数当成本项目结果。性能结论只来自 `结果/算法比较/正式/` 的实际运行。

数据与统计来源沿用 `Spark与服装数据.md`、`文献索引.json` 及数据文件校验清单。新增报告中的方法比较采用上述原始文献编号，和旧报告编号分开。
